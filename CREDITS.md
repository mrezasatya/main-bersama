# Kredit dan Lisensi Aset

## Ilustrasi

Semua ilustrasi (benda, stiker, ikon, ikon aplikasi) adalah SVG orisinal yang dibuat untuk proyek ini
di `src/core/art/` dan `public/favicon.svg`. Tidak memakai karakter, logo, atau merek berhak cipta.

## Font

- **Nunito** oleh Vernon Adams, Cyreal, Jacques Le Bailly — SIL Open Font License 1.1.
  Dibundel lewat paket `@fontsource/nunito` (tidak dimuat dari CDN saat runtime).

## Suara

- Ucapan: Web Speech API (`speechSynthesis`) memakai suara bawaan perangkat pengguna. Tidak ada rekaman yang dibundel.
- Nada dan efek: disintesis dengan Web Audio API. Tidak ada sampel audio.

## Lagu

Belum ada. Lagu tradisional hanya dipakai bila berstatus domain publik dan dicatat di sini.
