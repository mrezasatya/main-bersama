# Kredit dan Lisensi Aset

## Ilustrasi

Semua ilustrasi (benda, stiker, ikon, ikon aplikasi) adalah SVG orisinal yang dibuat untuk proyek ini
di `src/core/art/` dan `public/favicon.svg`. Tidak memakai karakter, logo, atau merek berhak cipta.

Bendera negara digambar sederhana (tanpa lambang kecil) untuk pengenalan anak. Uang rupiah digambar
sebagai bentuk sederhana dengan nilai tertulis, bukan tiruan uang asli. Rumah adat, wayang, ondel-ondel,
motif batik, dan landmark adalah ilustrasi orisinal yang disederhanakan; mohon ditinjau kesesuaiannya.

## Font

- **Nunito** oleh Vernon Adams, Cyreal, Jacques Le Bailly — SIL Open Font License 1.1.
  Dibundel lewat paket `@fontsource/nunito` (tidak dimuat dari CDN saat runtime).

## Suara

- Rekaman ucapan: dibuat dengan ElevenLabs Text-to-Speech (`npm run voice`), disimpan di `public/voice/`.
  Suara, model, dan tanggal pembuatan tercatat di `public/voice/manifest.json`.
  Ketentuan penggunaan bergantung pada paket langganan ElevenLabs saat rekaman dibuat
  (mis. paket gratis mensyaratkan atribusi dan tidak untuk penggunaan komersial); periksa ketentuan
  terbaru sebelum rilis atau monetisasi.
- Cadangan: Web Speech API (`speechSynthesis`) memakai suara bawaan perangkat pengguna.
- Nada dan efek: disintesis dengan Web Audio API. Tidak ada sampel audio.

## Lagu

Belum ada. Lagu tradisional hanya dipakai bila berstatus domain publik dan dicatat di sini.
